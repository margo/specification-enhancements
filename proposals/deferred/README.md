# Deferred SUPs

This directory holds **draft skeletons** of SUPs that are scoped out of the current PR 2 deliverables but represent known future work.

These are **not active SUPs**. They are not on the TWG decision path until promoted out of this directory and through the standard SUP workflow.

Each file captures:
- Content originally drafted as part of the larger MIAF SUP, before the SUP was split.
- The bootstrap method, profile, or feature it would standardize.
- Cross-references to the active MIAF SUP and its profiles.

**Promotion path:** when an item here becomes a PR 2 / GA1 priority, move it from `deferred/` to `proposals/`, complete the template's currently-unfilled sections (Owner, Requirements alignment), and proceed through the standard Phase 2 / Phase 3 process.

**Why these are not in active MIAF:** every item here is **purely additive** on top of the active MIAF SUP and the WFM Client Identity Profile. None of them require breaking changes to the active SUPs to land later. This is the design property that justifies the split.
